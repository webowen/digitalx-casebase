## 验收原则

- 正式名称不得直接复制文件名或宣传标题；
- 事实、来源方声明、AI 推断和未决事项必须分开；
- 正文只能引用证据包中的陈述；
- 联网失败只能降级，不能伪装成完整研究；
- 不兼容资料必须提前停止；
- 所有正式案例仍需人工复核后发布。
