## 4. 缺陷与处理

### P1：真实模型遗漏七章

现象：两次真实调用分别只返回4章和3章。

处理：

- 写作协议明确列出七个章节对象并要求不得省略；
- 协议层固定补齐缺失章节；
- 缺证据章节只显示待补充说明，不编造内容；
- 质量评分只统计拥有事实陈述支撑的实质章节。

状态：已修复并通过生产复验。

### P1：模型偶发返回空项目名称

现象：短材料复验中，身份模型和证据模型同时遗漏名称。

处理：

- 从原始资料中的“案例名称、项目名称、来源标题”等位置提取安全候选；
- 候选名称置信度不高于45%，强制进入人工核验；
- 联网证据仍可在后续阶段替换为更可靠的规范名称；
- 不兼容资料不使用候选回退。

状态：已修复并通过生产复验。

### P2：证据不足导致部分章节降级

现象：短材料缺少量化成效，完整案例缺少实施运营和复制条件证据。

判断：属于资料质量边界，不是程序缺陷。系统正确保留空章节、降低评分并阻止自动发布。

状态：作为人工复核和后续补充研究事项保留。
