# DigitalX V1.4 页面交互与验收标准

## 1. 桌面布局

- 顶部栏固定在页面顶部；
- 左侧目录宽度约 300–340px，可折叠；
- 中央地图占据剩余主要空间；
- 右侧工具栏宽度约 280–320px，可折叠；
- 案例预览悬浮在地图中央偏下，不永久遮挡全部地图。

## 2. 核心联动

### 目录到地图

1. 用户展开分类、地区或专题；
2. 点击案例；
3. 地图定位到案例所在城市；
4. 当前案例在目录中保持选中；
5. 中央出现案例快速预览。

### 地图到目录

1. 用户点击城市点位；
2. 当前筛选范围增加城市条件；
3. 左侧展示该城市的案例；
4. 默认选中该城市第一条案例；
5. 中央预览同步更新。

### 筛选到结果

- 关键词、分类、年份、证据条件共享同一筛选状态；
- 地图数量、目录数量、右侧统计和案例预览必须一致；
- 清空筛选后恢复全部公开案例；
- 当前案例被筛除时自动选择下一条可见案例或关闭预览。

## 3. 移动端

- 顶部保留品牌、搜索和目录按钮；
- 左侧目录变成覆盖式抽屉；
- 右侧工具变成覆盖式筛选面板；
- 案例预览使用底部卡片；
- 地图仍是主画布；
- 所有主要按钮触控高度不低于 44px。

## 4. 第一阶段验收

- [ ] `/`、`/admin`和现有案例详情无回归；
- [ ] `/workbench`可以独立打开；
- [ ] 地图高度随视口变化，不再固定为首页卡片高度；
- [ ] 分类、地区、专题目录均可切换；
- [ ] 目录可以展开并选中案例；
- [ ] 点击案例后显示正式项目名称、摘要、地区、证据等级；
- [ ] 点击城市点位后目录与预览同步；
- [ ] 分类、年份、证据和关键词筛选有效；
- [ ] 可以进入完整阅读器；
- [ ] 手机端目录和筛选面板可以打开、关闭；
- [ ] 页面没有横向溢出；
- [ ] TypeScript、Lint、构建和自动测试通过。

## 5. 后续性能门槛

正式数据库接入后再增加：

- 1000条案例下目录首次渲染不明显卡顿；
- 地图点位使用城市或网格聚合；
- 目录使用虚拟列表或按需加载；
- 筛选条件进入 URL，刷新和分享后能够恢复；
- 地图和目录状态建立统一 Store，避免多份状态漂移。
