# DigitalX V1.4 地图案例工作台产品需求

## 1. 版本目标

V1.4 将公开案例入口从“地图加案例卡片的展示型首页”升级为“以地图为主要画布、目录和筛选联动的案例研究工作台”。

本版本不重写 AI 解析器、案例数据模型、图片证据、管理端和阅读器。新工作台先在 `/workbench` 独立运行，验收通过前不替换 `/`。

## 2. 目标用户

- 需要快速检索同类项目的智慧城市、规划、工程数字化从业者；
- 需要按地区、分类和专题研究案例的售前与产品人员；
- 需要核对来源、证据和建设边界的研究人员；
- 需要从管理端发布后检查公开效果的案例管理员。

## 3. 核心任务

1. 从应用分类、地区或专题目录找到案例；
2. 在地图中理解案例的空间分布；
3. 通过关键词、年份和证据条件缩小范围；
4. 快速预览正式项目名称、图片、摘要和证据；
5. 进入完整阅读器继续阅读或研读；
6. 后续支持收藏、对比和 AI 自然语言检索。

## 4. 信息架构

| 区域 | 职责 | 第一阶段范围 |
|---|---|---|
| 顶部栏 | 品牌、全局搜索、视图与全局入口 | 实现 |
| 左侧目录 | 按分类、地区、专题组织案例 | 实现基础树 |
| 中央地图 | 城市分布、定位与当前案例预览 | 复用现有地图并重构容器 |
| 中央预览 | 当前案例摘要与阅读入口 | 实现 |
| 右侧工具 | 筛选、图层、统计、AI工具 | 实现基础筛选和统计 |
| 移动端 | 地图全屏、目录抽屉、案例底部卡片 | 实现基础适配 |

## 5. 本版本范围

### 必须实现

- 新增 `/workbench`，旧首页继续可用；
- 地图占据桌面主要可视区域；
- 左侧提供分类、地区、专题三种目录视图；
- 目录选择、地图城市和案例预览保持联动；
- 右侧提供分类、年份、证据筛选与结果统计；
- 案例预览可进入现有阅读器和研读模式；
- 本地已发布案例与内置公开案例使用同一入口；
- 桌面、平板、手机无横向溢出。

### 暂不实现

- 正式数据库和跨设备同步；
- 后端收藏、案例对比和用户权限；
- 行政区边界着色和热力分析；
- 万级案例虚拟树与服务端聚合；
- AI 自然语言检索的真实调用；
- 用新工作台替换 `/`。

## 6. 业务边界

- `/workbench`读取现有 `SmartCityCase`，不复制第二套案例实体；
- 省会锚点和城市中心推断仍需显示位置置信度；
- 未经人工复核的图片和案例不能因新界面自动公开；
- 左侧目录是案例的多维视图，不改变案例真实分类字段；
- 地图预览只承担快速判断，完整长文继续进入阅读器。
