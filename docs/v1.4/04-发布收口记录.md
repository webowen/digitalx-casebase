# DigitalX V1.4 发布收口记录

## 发布结论

V1.4 地图案例工作台已完成阶段验收，正式替代 V1.3 经典首页成为公开默认入口。后续功能开发统一从 V1.4 主版本继续，不再并行维护两套公开首页。

## 路由安排

| 路由 | 发布后定位 |
|---|---|
| `/` | V1.4 正式公开入口 |
| `/workbench` | V1.4 兼容入口，保留既有分享链接 |
| `/legacy` | V1.3 经典首页归档，不再新增功能 |
| `/admin` | 案例导入、AI解析、复核与发布 |
| `/cases/[slug]` | 案例阅读与研读 |

## 版本管理

- 正式开发主线：`main`
- 发布标签：`v1.4.0-map-workbench`
- V1.4 功能分支：合并后停止继续开发
- V1.3：通过既有 `v1.3.0` 标签和 `/legacy` 路由保留

## 验收范围

- 新版根路由、兼容路由与旧版归档路由可正常打开。
- 地图、目录、筛选、URL状态、中央案例预览和完整阅读入口保持可用。
- 管理端、AI解析、图片证据和案例阅读器未因首页切换发生行为变化。
- 类型检查、代码规范、生产构建和自动测试通过后方可发布。

## 后续开发原则

所有新功能从 `main` 的 V1.4 基线创建独立功能分支。旧版只用于回看，不接受新功能；需要恢复时优先通过 Git 标签或发布版本回滚，不复制新的长期维护分支。
