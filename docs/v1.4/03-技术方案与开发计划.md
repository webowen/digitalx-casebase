# DigitalX V1.4 技术方案与开发计划

## 1. 改造策略

采用渐进式替换：

```text
/                  继续承载 V1.3 稳定首页
/workbench         V1.4 地图案例工作台
/cases/[slug]      继续复用现有阅读器
/admin             继续复用现有管理端
```

新工作台验收前不改变 `/`，不修改案例生产流程，不迁移生产数据。

## 2. 复用与新增

| 模块 | 方案 |
|---|---|
| `SmartCityCase` | 原样复用 |
| 内置案例和本地案例 | 原样复用并合并公开数据 |
| 高德地图加载器 | 复用，增加自适应高度参数 |
| 阅读器 | 原样复用 |
| 管理端与AI接口 | 原样复用 |
| 工作台页面 | 新增 |
| 多维目录 | 第一阶段在工作台页面内实现，稳定后拆组件 |
| 状态管理 | 第一阶段使用页面级 React state |
| URL状态 | 后续阶段实现 |

## 3. 状态设计

第一阶段保持一份筛选状态：

```text
publishedCases
  → keyword/category/year/evidence/city
  → filteredCases
  → cityStats
  → tree groups
  → selectedCase
```

地图、目录、统计和预览全部从 `filteredCases`派生，不分别维护结果副本。

## 4. 分阶段开发

### 阶段一：基础工作台

- 路由、桌面布局、移动抽屉；
- 多维目录基础树；
- 地图自适应容器；
- 案例预览；
- 基础筛选和统计；
- 自动测试。

### 阶段二：深度联动

- 精确案例点位；
- 目录自动展开和滚动定位；
- URL状态；
- 行政区与城市层级切换；
- 收藏和最近浏览。

### 阶段三：专业研究工具

- 案例对比；
- 图层控制；
- 专题案例集；
- AI自然语言检索；
- 统计与导出。

### 阶段四：生产化

- 正式数据库；
- 用户权限；
- 服务端筛选和分页；
- 性能、日志与监控；
- 将新工作台切换为正式首页。

## 5. 发布策略

- V1.3稳定版本保持可回滚；
- V1.4使用独立功能分支；
- 每个阶段通过类型、规范、构建、自动测试和真实交互点测；
- 第一阶段只提交评审，不自动替换首页；
- 最终验收后合并 `main`并建立 `v1.4.0`稳定版本。
