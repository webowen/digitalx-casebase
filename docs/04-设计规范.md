# DigitalX 设计规范

本规范基于 `DESIGN-mintlify.md` 提炼，并结合当前 DigitalX V1 已实现界面形成产品级约束。目标不是复制 Mintlify 官网，而是采用其设计纪律：克制、高密度、文档感强、强调色使用节制。

## 1. 总体原则

- 白底、黑字、薄边框构成主要视觉；
- 薄荷绿只承担关键动作、当前状态和成功反馈；
- 公开站强调清晰检索，管理端强调高密度操作，阅读器强调连续阅读；
- 少用厚重阴影、彩色渐变和大面积色块；
- 真实业务信息层级优先于“看起来像科技平台”。

## 2. 色彩

| 角色 | 建议值 | 用法 |
|---|---|---|
| 主文字/主按钮 | `#0a0a0a` | 标题、关键文本、黑色主按钮 |
| 反白文字 | `#ffffff` | 黑色按钮和深色表面 |
| 品牌薄荷绿 | `#00d4a4` | 关键动作、选中、成功状态 |
| 深薄荷绿 | `#00b48a` | 按下、深色文本强调 |
| 页面底色 | `#ffffff` | 主要内容 |
| 次级底色 | `#f7f7f7` / `#fafafa` | 轻分区、控件背景 |
| 主边框 | `#e5e5e5` | 卡片、输入框、分隔线 |
| 主文字 | `#0a0a0a` | 标题 |
| 正文 | `#3a3a3c` | 连续正文 |
| 次级文字 | `#5a5a5c` | 元数据、说明 |
| 弱化文字 | `#888888` | 占位与提示 |
| 错误 | `#d45656` | 校验错误 |

业务类别可以使用既有分类色，但只用于圆点、标签等小面积识别，不成为页面主色。

## 3. 字体

- UI、标题、正文：Inter；
- 数据、代码、字段等确有需要时：Geist Mono；
- 不随意引入第三套字体。

常用层级：

| 场景 | 尺寸/字重 |
|---|---|
| 首页主标题 | 36–48px / 600 |
| 页面标题 | 28–36px / 600 |
| 区块标题 | 18–24px / 600 |
| 正文 | 16px / 400 / 1.5 行高 |
| 高密度业务正文 | 14px / 400–500 |
| 标签与辅助信息 | 11–13px / 500–600 |

阅读器正文必须保证舒适行高，不压缩成长表格式密度。

## 4. 圆角与形状

| 组件 | 圆角 |
|---|---|
| 小标签、代码 | 4–6px |
| 输入框、下拉框、紧凑控件 | 8px |
| 卡片、面板 | 12px |
| 大型内容面板 | 16px（谨慎使用） |
| 主要按钮、筛选胶囊 | 9999px |

同一组件家族不得混用多个相近圆角。

## 5. 间距

采用 4px 基础单位，常用 8、12、16、20、24、32、40、48、64px。

- 紧凑表单项：8–12px；
- 卡片内部：20–24px；
- 区块之间：32–48px；
- 大型营销区块：64–96px；
- 管理端允许更高信息密度，但不得挤压触控尺寸。

## 6. 组件规则

### 按钮

- 主要动作：黑底白字胶囊按钮；
- 品牌动作：薄荷绿胶囊按钮，每个首屏通常不超过一个；
- 次要动作：白底、薄边框胶囊按钮；
- 工具动作：8px 圆角的轻量按钮；
- 移动端有效触控高度不低于 44px。

### 输入框

- 高度 40px，移动端 44px；
- 8px 圆角、1px 薄边框；
- 聚焦时用薄荷绿边框或浅色外环；
- 错误状态必须同时有文字，不能只靠红色。

### 卡片

- 默认白底、1px 边框、12px 圆角；
- 不使用重阴影；悬浮提示可用极轻阴影；
- 卡片只用于确实独立的信息对象，不把连续文章每段都包成卡片。

### 状态与标签

- 当前步骤、成功状态可用薄荷绿；
- 错误用红色，警告用橙色；
- 业务分类色仅作为小面积编码；
- 同一屏幕避免出现大量不同颜色状态。

## 7. 页面专项规则

### 公开首页

- 第一视口回答“这是什么、能找什么、怎么开始”；
- 检索区优先于大面积装饰；
- 筛选项支持横向滚动或响应式重排；
- 地图、案例列表和城市选择必须保持明确联动。

### 管理端

- 桌面采用高密度多栏文档工作台；
- 左侧原始资料、中部结构化编辑、右侧质量/状态控制职责明确；
- 五步流程统一表达；
- 移动端按业务顺序折叠为单列，不照搬桌面三栏。

### 阅读器

- 阅读正文连续、克制，不套后台卡片；
- 工具栏、目录和设置面板遵循统一设计系统；
- 桌面可双页，移动端保持单页；
- 阅读主题可变，但不改变内容结构；
- 研读模式可以高密度，阅读模式优先舒适度。

## 8. 响应式

| 范围 | 重点 |
|---|---|
| `<480px` | 单列、44px 触控、36px 以内主标题 |
| `480–767px` | 单列为主，部分信息可双列 |
| `768–1023px` | 两栏或抽屉，阅读器单页 |
| `≥1024px` | 完整桌面布局，多栏管理和文档导航 |

所有页面都要检查：

- 无横向溢出；
- 下拉框和按钮可触控；
- 固定工具栏不遮挡内容；
- 地图有合理高度；
- 长标题、长标签、长来源链接可换行。

## 9. 禁止事项

- 不把薄荷绿用作大段正文或大面积背景；
- 不新增无业务含义的霓虹蓝、紫色渐变和玻璃拟态；
- 不用重阴影堆叠后台卡片；
- 不混用过多圆角；
- 不把阅读正文压缩成 14px 以下；
- 不为“科技感”牺牲字段、证据和流程的可读性。
