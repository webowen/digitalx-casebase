# 产品说明

## 1. 产品定位

DigitalX 城市数智应用案例库不是普通 PDF 收藏夹，也不是只按标题搜索的资讯库。它希望把分散在政策文件、招投标公告、新闻报道、企业案例、会议材料和研究报告中的城市数字化项目，转化为可检索、可比较、可研判、可追溯的结构化案例。

产品现阶段服务于个人研究和业务拓展，后续可扩展为团队知识库。

## 2. 目标用户

- 智慧城市、BIM/CIM/GIS、数字孪生解决方案人员；
- 政府数字化项目研究、规划和售前人员；
- 需要查找同类城市、同类场景和同类建设模式的产品经理；
- 需要从公开资料中提炼项目痛点、资金、建设内容、实施主体和成效的研究人员。

## 3. 核心问题

传统资料管理通常存在以下问题：

- 资料散落在网页、PDF、聊天记录和本地文件夹中；
- 只记得“看过”，无法快速按城市、行业、年份、阶段和证据检索；
- 不同来源口径混杂，宣传内容与可验证事实没有分开；
- 项目背景、资金来源、实施单位、运营单位和实际成效经常缺失；
- 找到资料后仍需重新阅读，难以直接形成项目判断；
- 个人新增内容无法形成稳定的发布与复用流程。

## 4. 产品闭环

```text
公开资料
  → 导入
  → 文本/AI解析
  → 结构化草稿
  → 人工复核
  → 位置确认
  → 发布入库
  → 地图/筛选检索
  → 阅读与研读
  → 支撑方案研究和业务判断
```

V1 已完整呈现这条流程的界面和交互，但数据仍以模拟案例和浏览器本地保存为主。

## 5. 页面职责

### 公开首页

解决“有什么案例、在哪里、属于什么场景、证据是否可用”的问题。

- 关键词搜索；
- 分类、地区、年份、空间层级、证据等级和来源类型筛选；
- 地图观察城市分布；
- 城市与案例联动；
- 进入案例详情。

### 案例阅读器

解决“把一个案例顺畅读完”的问题。

- 书籍式正文排版；
- 目录定位；
- 滚动与分页；
- 桌面单双页及移动单页；
- 主题、字号和阅读进度本地保存。

### 研读模式

解决“快速判断这个项目值不值得借鉴”的问题。

- 项目基本事实；
- 痛点、建设内容和成效；
- 投资、资金、实施和运营信息；
- 案例库专业研判；
- 来源与证据等级。

### 管理工作台

解决“如何把一份资料变成可发布案例”的问题。

- 网页、粘贴文本和本地文件入口；
- AI 解析演示；
- 结构化字段编辑；
- 人工复核；
- 位置和证据确认；
- 草稿、待复核、发布状态；
- 浏览器本地案例管理。

## 6. 与普通案例库的差异

DigitalX 的差异不在“收了多少篇文章”，而在于每个案例都尽量形成：

- 可定位的城市和空间层级；
- 可比较的项目类别和建设阶段；
- 可追溯的来源；
- 明确的证据等级；
- 痛点、方案、投资、主体、成效和适用边界；
- 原始事实与案例库判断分开表达。
