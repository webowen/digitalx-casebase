## 接收方复验

解压后建议在新目录执行：

```bash
npm ci
npm run typecheck
npm run dev
```

正式接手时，再在 Git Bash、WSL 或 Linux 环境执行：

```bash
npm run lint
npm test
```

若未配置高德地图变量，地图会提示配置缺失；这不影响首页其他内容、管理端和案例阅读器的本地启动。
