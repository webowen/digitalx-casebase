# V1 功能边界

## 1. 版本定义

当前版本为 **V1.0 高保真、可交互、已上线的前端原型**，用于验证产品结构、页面关系、业务流程和视觉体验。它不是正式生产系统。

## 2. 功能状态

| 功能 | 当前状态 | 说明 |
|---|---|---|
| 首页与导航 | 已真实实现 | 可正常访问和跳转 |
| 关键词搜索 | 已真实实现 | 在浏览器内对现有案例字段匹配 |
| 多条件筛选 | 已真实实现 | 分类、地区、年份、层级、证据、来源可组合 |
| 地图展示 | 已真实实现 | 接入高德地图，需配置 Key 与安全密钥 |
| 城市聚合与联动 | 已真实实现 | 地图点、城市面板和案例列表联动 |
| 案例详情 | 已真实实现 | 可读取内置和本地已发布案例 |
| 阅读/研读切换 | 已真实实现 | 两种模式读取同一案例对象 |
| 滚动/分页/单双页 | 已真实实现 | 含响应式适配 |
| 主题、字号、阅读进度 | 浏览器本地实现 | 保存在 `localStorage` |
| 草稿/待复核/发布 | 浏览器本地实现 | 刷新不消失，但不跨设备 |
| 文件选择入口 | 部分真实实现 | 支持将最大 8MB 的 PDF 随单次解析请求发送给当前AI服务，但不保存原文件 |
| AI 解析 | Alpha 真实实现 | 默认调用 Gemini，亦可切换 OpenAI；以严格 JSON Schema 返回案例草稿、证据、置信度和待核验项 |
| OCR/PDF/网页正文提取 | 部分真实实现 | PDF 由当前模型的文档输入处理；网页需人工粘贴正文，尚无独立 OCR、网页抓取或异步任务 |
| 正式数据库 | 尚未实现 | `db/schema.ts` 当前为空 |
| 用户账号与权限 | 尚未实现 | 管理端没有真实鉴权 |
| 审核日志与版本历史 | 尚未实现 | 无操作人和版本追踪 |
| 云端文件存储 | 尚未实现 | 无对象存储 |
| 跨设备同步 | 尚未实现 | 数据停留在单个浏览器 |
| AI问答、语义检索 | 尚未实现 | 不在 V1 范围 |

## 3. 当前数据来源

### 内置演示数据

位置：`lib/mock-cases.ts`

作用：保证首次打开产品时就有可检索、可阅读的代表案例。它们属于产品样例，不应自动视为完整、最新或已经过第三方核验的正式数据库。

### 浏览器本地数据

位置：浏览器 `localStorage`

主要键：

- `digitalx-casebase-local-cases-v1`：管理端新增案例；
- `digitalx-reader-{slug}`：单个案例的阅读偏好和进度。

清理浏览器数据、切换浏览器或换电脑后，本地数据不会自动迁移。

## 4. 当前验收基线

V1 应持续满足：

1. 首页、管理端和案例详情均可打开；
2. 搜索与多条件筛选结果正确；
3. 地图选择城市后，案例列表同步变化；
4. 管理端可载入测试资料并完成真实 AI 解析；API 不可用时展示明确错误；
5. 草稿、待复核和发布状态可在本地保存；
6. 已发布本地案例可出现在首页并进入详情；
7. 阅读/研读切换、滚动/分页和主题设置可用；
8. 桌面与手机无明显横向溢出；
9. 构建、类型检查和现有自动测试通过；
10. 所有说明明确区分真实功能、浏览器本地功能和模拟功能。

## 5. 已知技术债

- `app/globals.css`、管理端、首页和阅读器文件偏大；
- 页面逻辑、业务组件和数据访问层尚未充分拆分；
- 状态管理以组件本地状态为主；
- 自动测试只覆盖最低构建与渲染门槛；
- 内置数据与用户新增数据尚未统一到仓储/服务层；
- 正式错误日志、性能监控和无障碍测试尚未建立。

以上问题不要求推倒重写，应随真实业务闭环开发逐步拆分。
