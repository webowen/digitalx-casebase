# V1.5.0-alpha.4 标杆终审与媒体证据

## 阶段目标

本阶段把三份标杆样稿从“AI 已整理”推进到“可由内容负责人逐项终审”，同时恢复地图作为主要交互空间。

## 地图交互

1. 点击左侧目录案例，仅定位项目坐标并显示 POI 信息气泡。
2. POI 气泡由高德地图 Marker 承载，跟随地图平移和缩放。
3. 点击地图点位或气泡后，才在当前界面打开内嵌案例文档。
4. 关闭文档后回到同一地图位置和已选案例。

## 六项终审门槛

| 门槛 | 核验内容 |
|---|---|
| 项目身份 | 正式名称、别名、范围和主体 |
| 来源 | 出版物、发布机构、链接和发布时间 |
| 关键陈述 | 陈述与来源关联、冲突和推断边界 |
| 量化指标 | 数值、单位、周期、基线和统计口径 |
| 媒体 | 图片来源、版权风险、图注、无障碍文本和插入章节 |
| 正文 | 七章结构、主次关系、重复内容和事实边界 |

六项门槛只能由内容负责人主动批准，AI 不自动代签。全部通过后，案例迁移状态才允许变为 `approved`。

## 媒体证据

管理端支持填写权威网页原图地址和图注。服务端保存图片副本及原始来源地址，新图片默认 `reviewed=false`。发布前必须人工核对原图、图注、章节和无障碍说明。

## 验收标准

- 页面底部不再出现独立 POI 卡。
- 地图气泡绑定所选案例坐标。
- 三份标杆案例均显示六项门槛及进度。
- 没有媒体时仍可进入媒体证据工作流。
- 未全部批准的迁移案例不能被标记为终审完成。
